# คำอธิบายข้อมูล (Data Description)

โฟลเดอร์นี้อธิบายข้อมูลที่ใช้ในโครงงาน **Food Order & Delivery Analysis**

## 1. แหล่งที่มาและสิทธิ์การใช้ข้อมูล

| หัวข้อ | รายละเอียด |
| --- | --- |
| ชื่อชุดข้อมูล | Food Order Delivery Dataset |
| แหล่งที่มาเดิม | https://www.kaggle.com/datasets/srisyra02/food-order-delivery-dataset |
| ประเภทข้อมูล | ข้อมูลคำสั่งซื้ออาหารและการจัดส่ง 1 แถวต่อ 1 ออเดอร์ ช่วงวันที่ 1 – 16 มิถุนายน 2025 ครอบคลุม 7 เมืองในประเทศอียิปต์ |

## 2. ไฟล์ในโฟลเดอร์นี้

| ตำแหน่งไฟล์ | คำอธิบาย |
| --- | --- |
| `Order_delivery1.csv` | ไฟล์ข้อมูลออเดอร์ มี 100,002 แถว 23 คอลัมน์ **ไม่มีค่าว่างและไม่มีแถวซ้ำ** |
| `New22221.ipynb` | Jupyter Notebook สำหรับวิเคราะห์ความสัมพันธ์ระหว่าง `Quantity` กับ `Total_Price` และสร้างโมเดล Linear / Polynomial Regression |

วิธีรันซ้ำ: วางไฟล์ CSV ไว้โฟลเดอร์เดียวกับ Notebook แก้ตัวแปร `CSV_PATH` ให้ตรงกับชื่อไฟล์จริง (ใน Notebook ใช้ชื่อ `Order_delivery.csv`) แล้วรันเซลล์ตามลำดับ ไลบรารีที่ใช้: numpy, pandas, matplotlib, seaborn, scikit-learn

## 3. พจนานุกรมข้อมูล (Data Dictionary) ของ `Order_delivery1.csv`

ข้อมูลมีทั้งหมด 100,002 แถว ตารางต่อไปนี้แสดงชื่อคอลัมน์ ชนิดข้อมูล คำอธิบาย และจำนวนค่าว่างของแต่ละคอลัมน์

| คอลัมน์ | ชนิดข้อมูล | คำอธิบาย / ค่าที่เป็นไปได้ | ค่าว่าง |
| --- | --- | --- | ---: |
| `Order_ID` | ตัวเลข | รหัสออเดอร์ (1 – 100,002) ไม่ซ้ำกัน | 0 |
| `User_ID` | ข้อความ | รหัสลูกค้า รูปแบบ `U####` มี 9,000 ราย | 0 |
| `Restaurant_ID` | ตัวเลข | รหัสร้านอาหาร (1 – 1,000) | 0 |
| `Driver_ID` | ตัวเลข | รหัสคนขับ (1 – 500) | 0 |
| `Item_Name` | ข้อความ | เมนูที่สั่ง ได้แก่ Shawarma, Pizza, Fried Chicken, Burger, Pasta, Sandwich, Koshary, Sushi และ Salad | 0 |
| `Quantity` | ตัวเลข | จำนวนชิ้นต่อออเดอร์ (1 – 5) เป็นตัวแปรหลักในการวิเคราะห์ | 0 |
| `Total_Price` | ตัวเลข | ราคารวมของออเดอร์ (30 – 750 เฉลี่ยประมาณ 268.9) เป็นตัวแปรหลักในการวิเคราะห์ | 0 |
| `Order_Time` | ข้อความ (วันเวลา) | เวลาที่สั่งอาหาร รูปแบบ `วัน/เดือน/ปี ชั่วโมง:นาที` | 0 |
| `Delivery_Time` | ข้อความ (วันเวลา) | เวลาที่จัดส่งถึงลูกค้า รูปแบบเดียวกับ `Order_Time` | 0 |
| `Delivery_Duration_Minutes` | ตัวเลข | ระยะเวลาจัดส่งเป็นนาที (15 – 60 เฉลี่ยประมาณ 37.5) เท่ากับ `Delivery_Time` − `Order_Time` ทุกแถว | 0 |
| `City` | ข้อความ | เมืองที่จัดส่ง ได้แก่ Cairo, Giza, Alexandria, Mansoura, Tanta, Zagazig และ Assiut | 0 |
| `Payment_Method` | ข้อความ | วิธีชำระเงิน ได้แก่ Cash, Wallet และ Credit Card | 0 |
| `Order_Status` | ข้อความ | สถานะออเดอร์ ได้แก่ Delivered (85,199), Cancelled (9,812) และ In Transit (4,991) | 0 |
| `Driver_Vehicle` | ข้อความ | พาหนะของคนขับ ได้แก่ Bicycle, Car และ Motorbike | 0 |
| `Restaurant_Lat` | ตัวเลข | ละติจูดของร้านอาหาร | 0 |
| `Restaurant_Lon` | ตัวเลข | ลองจิจูดของร้านอาหาร | 0 |
| `Customer_Lat` | ตัวเลข | ละติจูดของลูกค้า | 0 |
| `Customer_Lon` | ตัวเลข | ลองจิจูดของลูกค้า | 0 |
| `Driver_Lat` | ตัวเลข | ละติจูดของคนขับ | 0 |
| `Driver_Lon` | ตัวเลข | ลองจิจูดของคนขับ | 0 |
| `Delivery_Distance_km` | ตัวเลข | ระยะทางจัดส่งเป็นกิโลเมตร (0.01 – 5.60 เฉลี่ยประมาณ 2.17) | 0 |
| `Traffic_Level` | ข้อความ | ระดับการจราจร ได้แก่ Low, Medium และ High | 0 |
| `Driver_Availability` | ข้อความ | สถานะคนขับ ได้แก่ Online และ Offline | 0 |

**หมายเหตุ**
- จำนวนค่าว่าง (Missing Values) นับจากข้อมูลทั้งหมด 100,002 แถว
- หน่วยของ `Total_Price` ไม่ได้ระบุไว้ในแหล่งข้อมูลเดิม
